# Atizaz

Applied machine learning projects, written for graduate applications.

## Projects

### [Skinalyze AI](https://github.com/atizazhusyn/skinalyze-ai)

Mobile app and Flask API that classify a skin photo into six conditions with a PyTorch ensemble, then store history and follow-up notes for each signed-in user.

### [Pakistan House Price Prediction](https://github.com/atizazhusyn/Pakistan-House-Price-Prediction)

Regression model and web app that estimate listing prices in Pakistani cities from property type, location, size, and room counts.

## Tools

Python, pandas, scikit-learn, PyTorch, Flask, React Native, Firebase
